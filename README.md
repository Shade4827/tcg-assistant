# tcg-assistant

TCG(MtG、遊戯王)で使うことを想定し、ツールをまとめたWebアプリケーションです

## Features

- ルアゴイフカウンター
- マナカウンター
- 紋章管理
- 呪文を唱えた回数カウント
- 権利行使チェック
- ダイス
- コイントス

## Setup

```
git clone git@github.com:Shade4827/tcg-assistant.git
cd tcg-assistant
pnpm install
pnpm dev
```

## Build

```
pnpm build
```

## Deploy

手動でデプロイする場合は下記のコマンドを使用します

```
pnpm wrangler deploy
```
